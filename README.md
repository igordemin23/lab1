# Лабораторная работа №1: Цветовые модели
**Вариант 12: RGB ↔ XYZ ↔ HLS**

Данное приложение представляет собой графический интерфейс (GUI) для интерактивного выбора и конвертации цветов между тремя цветовыми моделями: **RGB, XYZ и HLS**. 

## Основные возможности
*   **Три способа задания цвета:**
    1.  Ввод точных числовых значений в текстовые поля.
    2.  Выбор цвета из системной палитры (аналогично графическим редакторам).
    3.  Использование кнопки "Применить" для моментального пересчета.
*   **Автоматический пересчет:** При изменении любой компоненты цвета в одной модели, значения в двух других моделях пересчитываются мгновенно.
*   **Обработка некорректных цветов (Clamping):** Если при переводе (например, из XYZ в RGB) значения выходят за допустимые границы, программа обрезает их до корректных и выводит ненавязчивое предупреждение пользователю.
*   **Соблюдение требований UPD 2026-09-23:** Интерфейс и математика адаптированы для работы исключительно с **целыми числами**. Дробные значения при вводе и отображении принудительно округляются.

## Архитектура проекта (MVC)
Проект разделен на независимые слои согласно заданию:
*   **Model (Модель)** — функции `rgb_to_xyz`, `xyz_to_rgb`, `rgb_to_hls`, `hls_to_rgb` и вспомогательные функции (гамма-коррекция, clamp). Чистая математика, не зависящая от интерфейса.
*   **View (Представление)** — класс `ColorApp` на базе библиотеки `tkinter`. Отвечает только за отрисовку элементов интерфейса, прием событий мыши и клавиатуры.
*   **Controller / ViewModel (Связующее звено)** — класс `ColorController`. Хранит текущее состояние цвета (в трех моделях), вызывает математические функции, проверяет выход за границы (клиппинг) и формирует предупреждения.

## Автоматические тесты
В приложении реализованы автоматические микро-тесты для проверки математики (функция `run_tests()`). 
Тесты проверяют:
1.  Корректность перевода `RGB(255,0,0)` в XYZ и обратно.
2.  Корректность перевода `RGB(0,255,0)` в HLS и обратно.
3.  Срабатывание механизма обрезки (clipping) при выходе значений за пределы RGB.

*При запуске программы результаты тестов выводятся в консоль.*
